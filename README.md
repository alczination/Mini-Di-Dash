# MiniDiDash
MiniDiDash is an open-source digital instrument cluster project designed to replace or augment the traditional center/steering column gauges in first-generation Mini Coopers (2001–2006). By tapping into the car’s OBD-II or CAN bus data, MiniDiDash provides real-time telemetry with a modern, customizable interface.
